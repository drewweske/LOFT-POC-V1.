# Camera + Map 001 — Trust the line

Trigger:
The user successfully completed all three demo holes. The remaining immediate friction was visual trust: putting camera composition still felt angled, and the course map was too small to serve precision play.

Largest meaningful gap:
The camera and map did not yet reinforce the same shot intention strongly enough.

Rebuild:
- putting address camera moved onto the intended roll axis
- putting swing lock keeps the same axis
- putting roll camera removes most lateral drift
- gentler putting yaw / pitch sensitivity
- larger compact topo map
- tap-to-expand map
- focused expanded map state
- reversible map-to-world projection
- drag expanded map to author aim direction + target distance
- contextual FT / YD map units
- smooth return from map to 3D camera

Design rule:
The player should always know where the ball is supposed to go.

3D view and 2D map are two views of ONE shot intention, never two separate systems.
