# Integration 038 — Purpose-built wedge soles

Retained locally: 2026-09-08. Entry `game.js?v=038-final`. Baseline `309d09f`.
Official main remains the Integration 035 assessment; no hosting or push performed.

## Reference / gap / definition of great

The Bag and zero-brand object boards require tools whose purpose is in their physical
construction. PW and SW previously shared an identical 15 mm-wide, 544-triangle capsule
bar despite different shot data. Great for this bounded iteration is a narrow pitching
platform and wider relieved sand platform in the actual held assembly, not new labels.
Faces, neck sockets, grips, rigid stations, motion, profiles and golf numbers are frozen.

## Built and observed

- A closed indexed metal support surface replaces only each wedge's sole mesh.
- PW working width is 20 mm; SW is 38 mm (1.90×). Both have convex camber, trailing
  relief and heel/toe lift. Higher grades refine that relief while retaining the
  family purpose. Each sole is 960 triangles and one existing draw, with shared
  body material rather than a rubber-like dark bar. No new dependencies or textures.
- The first valid candidate still looked padded. Tight machining shoulders and
  analytic broad-surface normals replaced edge-to-cap averaged cushion shading.
- This is a bounded improvement, not production club modeling: the thick shared
  face/back outline and heavy proportions still fall below the reference objects.

## Evidence / preservation

74/74: Visual37 + Terrain14 + Ball6 + Assembly1 + Atelier5 + Neck4 + Forging3 + Sole4.

The independent sole suite checks real triangle cross-sections, ray-probed camber,
trailing/heel/toe relief, welded manifold winding, finite normals, thickness/no-fold
probes, actual transformed ground minima and triangle/ball distance. Deliberate open,
flattened, narrowed and buried mutations were rejected in isolated test processes.

Before geometry work, literal hash
`158f1c8be87bf4014e2403ef6b19d591ce985102dba98cdba143e3d78e0aa2cd`
froze all non-sole parts, full four-station poses, profiles and complete CLUBS data
against 037. It still matches. Historical 035/036/037 hashes remain recorded; no
silently regenerated baseline. Held and inspected soles use identical buffers/materials.

The old transformed local AABB falsely implied more penetration than the actual mesh
and understated Foundation address hover. New wedge ground checks use actual vertices.
Independent per-grade/phase baselines prevent increased penetration and allow at most
2 mm extra hover. The former Foundation sole impact minimum was −0.489 mm; the new
surface stays above the plane. The addressed ball retains more than 1 mm sole clearance.
The old positive Foundation hover is NOT declared fixed. Static low-grade impact face/
ball overlap predates this work; this pass did not alter the animation/launch handoff.
